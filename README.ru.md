# Pekarnya - Система заказов онлайн-пекарни

Учебный проект онлайн-пекарни на Laravel 10 с использованием MySQL.

## Использованные возможности Laravel

- Eloquent ORM для работы с базой данных и связями
- Шаблонизатор Blade с макетами и компонентами
- Middleware для аутентификации и защиты маршрутов
- Миграции для управления схемой базы данных
- Сидеры и фабрики для генерации тестовых данных
- Form Requests для выделенных классов валидации
- Route Model Binding для автоматической инъекции моделей
- Service Container для внедрения зависимостей
- Управление сессиями для работы с корзиной
- Artisan CLI для управления проектом

## Технологии

- Backend: PHP 8.1+, Laravel 10.10
- База данных: MySQL
- Аутентификация: Laravel Sanctum
- Frontend: Blade, HTML5, CSS3, JavaScript
- Сборщик: Vite
- Тестирование: PHPUnit

## Архитектурные решения
- MVC архитектура - разделение ответственности (Models, Views, Controllers)
- Eloquent связи - hasMany, belongsTo для заказов, товаров, адресов
- Middleware группы - защита авторизованных маршрутов
- Resource контроллеры - RESTful подход для CRUD операций
- Blade компоненты - переиспользуемые UI компоненты
- Form Requests - выделенные классы валидации
- Транзакции базы данных - обеспечение целостности данных при оформлении заказа

## Реализованные возможности
### Система авторизации
- Регистрация пользователей с валидацией
- Вход/выход из системы
- Аутентификация на основе сессий
- Защищённые маршруты через middleware

### Меню и категории
- Структура меню по категориям
- Динамическая генерация меню из базы данных
- Страницы отдельных товаров с деталями
- Фильтрация по категориям

### Корзина покупок
- Добавление товаров в корзину
- Обновление количества товаров
- Удаление товаров из корзины
- Сохранение корзины в сессии
- Расчёт итоговой суммы в реальном времени

### Управление заказами
- Оформление заказа с выбором адреса
- Несколько адресов доставки на пользователя
- Отслеживание активных заказов
- История заказов
- Пометка заказов как завершённых

### Профиль пользователя
- Просмотр информации профиля
- Управление адресами доставки:
  - Добавление новых адресов
  - Удаление существующих адресов
  - Поддержка нескольких адресов
